# 클리커게임

클릭해서 돈을 모으고, 직원을 고용하고, 도박도 하면서 목표 금액을 모으는 한국어 방치형(클리커) 게임입니다. 순수 HTML/CSS/JS로만 만들어져 있고 빌드 과정이 없습니다.

## 실행 방법

`index.html` 파일을 브라우저로 열기만 하면 됩니다. 별도 설치나 빌드가 필요 없습니다.

```
index.html 더블클릭 (또는 브라우저 주소창에 파일 경로 입력)
```

로컬 정적 서버로 띄우고 싶다면(선택 사항):

```
npx serve .
```

## 주요 기능

- 클릭으로 돈 모으기 + 클릭 업그레이드
- 5개 테마 × 3명, 총 15명의 직원 고용/강화 (자동 수익)
- 돌림판 도박 (최저 확률로 "캐릭터2" 모드 진입)
- "인생한방" 고위험 이벤트 (캐릭터2 모드 + 최종 Stage 전용)
- 도전과제(업적) 15개
- 저장 슬롯 3개, 배속(×1/×2/×3) 설정
- 설정 화면의 "이미지 커스텀"에서 캐릭터1/캐릭터2/직원 15명/테마 5개 각각의 이름·이모지·이미지·움직임·말풍선을 자유롭게 바꿀 수 있습니다(기본 이미지는 없고, 업로드한 이미지가 없으면 이모지로 표시됩니다).
